# Beginner-friendly UI update

The game keeps the same multiplayer rules, abilities, buildings, laws, alliances, crises and scoring. Only the presentation and instructions were simplified.

- Next-step panel on every active phase
- How to play popup with 5-step overview and building costs
- Plain-language button labels, resource tooltips, and island power descriptions
- Clearer Core crisis instructions
- Solara power selects a player by numbered name, not internal seat ID

Run: `pip install -r requirements.txt` then `python -m uvicorn server:app --port 8000`.
